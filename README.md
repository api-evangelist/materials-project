The Materials Project API provides direct access to the Materials Project database, a large-scale computational materials science database with data on tens of thousands of materials. The API is offered free of charge and supports machine learning, automated analysis, and bulk data downloads.

**Areas:** Chemistry · Materials Science · Physics · Research · Scientific Computing

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Materials Project: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
